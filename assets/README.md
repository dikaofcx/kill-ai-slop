# Assets

Direktori ini hanya untuk aset yang dibutuhkan plugin atau dokumentasi.

Tambahkan aset yang dibuat untuk proyek atau punya lisensi yang jelas. Hindari screenshot produk rekaan, logo pihak lain, font tanpa izin, atau gambar stok yang tidak menambah informasi. Jika aset ditambahkan, dokumentasikan sumber/lisensinya dan periksa kontras, skala, serta jalur di manifest sebelum rilis.
