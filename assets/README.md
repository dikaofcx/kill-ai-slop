# Assets

Direktori ini menyimpan aset plugin dan dokumentasi yang memang membantu menjelaskan proyek.

- `banner.png` dan `logo.png` adalah identitas visual repo.
- `quality-loop.mmd` / `quality-loop.png` menjelaskan alur audit berbasis konteks dan bukti.
- `harness-layers.mmd` / `harness-layers.png` menjelaskan pemisahan pemeriksaan deterministik, fungsi, dan review manusia.

Dua diagram README dibuat dari sumber Mermaid yang disimpan bersama PNG-nya; tidak memakai aset stok atau logo pihak lain. Jika diagram berubah, edit file `.mmd`, render ulang dengan `manus-render-diagram`, lalu cek jalur dan keterbacaan di layar kecil.

Untuk aset baru, simpan sumber dan lisensi yang jelas. Hindari screenshot produk rekaan, font tanpa izin, serta gambar dekoratif yang tidak menambah informasi. Periksa kontras, skala, dan jalur di manifest sebelum rilis.
